# Security

The web server (`hexfield-web`) is meant to be reachable by other people, so security
problems in it matter. They include ways to read another player's hand, act for another
seat, reach the host-only actions without the host key, or take the server down.

Please report them privately, through **Security → Report a vulnerability** on the GitHub
repository, rather than in a public issue.

Only the latest release is supported.
